# Contributing

Run `PYTHONPATH=src python -m unittest discover -s tests -v` and include the smallest meaningful reproduction. The offline suite requires no API key; a model experiment must be explicitly labeled and retain actual receipts.

For a new evolvable mechanism, describe its inputs, permitted effects, fixed boundaries, expected decision change and discriminating experiment. Do not modify grading or held-out tasks to make a candidate pass. Include rejected/negative outcomes and compare equal model/tool/feedback conditions.

Do not attach private usage traces or company data. Add synthetic fixtures with clear provenance. Research references must identify exact source versions and separate author claims from our execution results.

Changes to permissions, approval, data sharing, tenant boundaries or the scoring protocol require maintainer review outside the autonomous evolution path.
