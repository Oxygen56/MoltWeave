# v0.2 冻结实验的独立复现

`scripts/reproduce_continual.py` 默认只做离线检查，不创建模型客户端、不导入冻结实验包、不调用 API。实际 `run` 和 `evaluate` 都需要显式 `--phase`，使用独立的用户复现目录。原始实验、冻结源码、旧回执均不改写。

本文提供复现流程，不认证原始实验当前是进行中、中断还是完成；请同时查看原始 summary 和后续维护 ledger。本文不代表它已通过验收或已经发布。目标原始目录为 `experiments/continual-v02-main`，manifest 计划为 20 轮、seed 101–110、三个实验臂。脚本从指定 manifest 读取轮数和 seeds，不用当前代码默认值替代原合同。

## 先取得证据并检查

正式结果完成 600/600 次提交及全部独立读出，完整证据附件为 [v0.2.0](https://github.com/Oxygen56/MoltWeave/releases/tag/v0.2.0) 中的 `moltweave-v02-complete-evidence.tar.gz`。完整读出没有证明演化 P 的独立收益，见[中文结论](v0.2-results.zh-CN.md)。海量 `model-calls` 不放进 Git，而由 release 附件、独立 SHA256 和逐文件 JSONL 清单分发。

此前 [v0.2.0-preview.1](https://github.com/Oxygen56/MoltWeave/releases/tag/v0.2.0-preview.1) 的约 198 MB／3.665 GB 历史快照停于 501/600 次提交、尚未独立读出；该附件保持不变，不能当作最终结果。原演化 summary 的 `all_versions_frozen_pending_readout` 是演化封存阶段状态，最终独立状态另见 `independent.json: completed`，不要为消除措辞差异改写原 summary。

在一份全新仓库副本中，核对可信发布校验和并检查压缩包目录后，解压到仓库根目录。包内相对路径恢复 `experiments/continual-v02-main/...`。不要覆盖已有同名实验或失败记录；示例中的 archive 文件名应替换为实际附件名。

```sh
tar -tzf moltweave-v02-complete-evidence.tar.gz
tar -xzf moltweave-v02-complete-evidence.tar.gz -C /path/to/fresh/MoltWeave
cd /path/to/fresh/MoltWeave
python3 scripts/reproduce_continual.py --check
```

`--check` 与不传阶段等价。也可以指定另一份原始归档，或用发布者另行给出的 manifest 原始文件 SHA256 固定来源：

```sh
python3 scripts/reproduce_continual.py --check \
  --experiment experiments/continual-v02-main \
  --manifest-sha256 RELEASE_MANIFEST_SHA256
```

离线检查验证 manifest 的九个 `sources`：`continual.py`、`continual_environment.py`、`continual_runtime.py`、`continual_memory.py`、`continual_program.py`、`continual_policy.py`、`program.py`、`common.py`、`llm.py`。这些 digest 是 `sha256(canonical_json(source_text))`，不是文件原始字节 SHA256。额外的 `__init__.py` 必须恰好只有冻结包声明的 docstring；符号链接、越界文件名和额外 Python 模块会被拒绝。

digest 证明文件与这份 manifest 一致，不证明 manifest 来自可信发布者。不要把任意下载者同时修改的源码与 manifest 当成可信包。`--manifest-sha256` 是额外固定点，仍应从可信发布记录取得。

离线检查不验证当前 API 凭据可用，也不执行模型。原始运行尚未完成时，源码检查仍可通过；这不能当成实验完成回执。

## 显式重新运行

需要 Python 3.11+。先按项目既有规则在本机配置与原 manifest 一致的请求模型、HTTPS 地址及同组密钥。不要把密钥放进命令参数、仓库文件或文档。legacy OPENAI／ANTHROPIC 密钥必须同时配置对应 BASE_URL；不能把一组密钥借给另一组地址。

```sh
python3 scripts/reproduce_continual.py --phase run \
  --experiment experiments/continual-v02-main \
  --output private/my-v02-reproduction \
  --concurrency 32
```

这一步会产生真实 API 调用及费用。输出目录必须完全不存在，不能是原实验、其子目录、祖先目录或指向原实验的别名；即使原位置只有空目录，也不会覆盖。已失败的同名复现标记也保留，换一个新目录重新开始。

入口先把校验过的九份源码与 docstring `__init__` 复制到私有临时包，不复制缓存字节码或当前开发源码。子进程使用参数列表执行 `python -B -S -P -m moltweave.continual run`，限定 PYTHONPATH、关闭外部 site 导入与环境代理。不会用 shell 拼接参数。

真正请求之前，冻结 `ModelClient` 自己解析凭据、地址和模型；无网络 preflight 验证它与原 manifest 的请求 model/provider 完全匹配，且要求 HTTPS、拒绝重定向、禁止环境代理。还会用冻结 host 核对源码和任务分区合同。wrapper 不替换密钥、不放宽 transport，也不把地址／模型差异偷偷改成原值。配置不一致时先拒绝，不花模型请求。

每个阶段在新输出旁保存一个不可覆盖的 `.OUTPUT.continual-reproduction-PHASE.json`，记录原 manifest hash、源码合同、参数列表及 wrapper hash，不写密钥。它是本机溯源记录，不是身份签名或实验成功认证。子进程中止或测量失败时，原始调用和标记继续保留。

## 独立评估新复现目录

只有此前由本入口创建的**不同于原实验的新复现目录**可以进入评估。它必须已有全部 streams／arms／versions、完成 summary、匹配的源码与实验合同、未变的版本 hash 和父子链；不能已有 `independent.json`、部分 `independent/`、`policy-audits/` 或其他 readout 输出。

```sh
python3 scripts/reproduce_continual.py --check \
  --experiment experiments/continual-v02-main \
  --output private/my-v02-reproduction

python3 scripts/reproduce_continual.py --phase evaluate \
  --experiment experiments/continual-v02-main \
  --output private/my-v02-reproduction \
  --concurrency 32
```

`--check --output` 只检查目标是否适合下一步：新目录按 run 保护规则检查，已存在目录按 evaluate 完整性规则检查。它不会开始评估。显式 evaluate 才使用同一冻结包执行 `python -m moltweave.continual evaluate`；冻结 host 自己再次检查 requested model、endpoint、分区和版本。已经中断的部分 readout 也不能在原位覆盖重测。

## 分析与结果边界

冻结包只有九份执行源码和 `__init__`，**不包含 `continual_analysis.py`**。完成复现读出后，可单独用当前维护包生成分析，并记录使用的 Git 版本；这属于分析层，不替换冻结执行／评分来源：

```sh
PYTHONPATH=src python3 -m moltweave.continual analyze --output private/my-v02-reproduction
```

请求 alias 相同不代表底层模型版本永久固定。即使 temperature=0，同一 provider 也可能产生不同输出；模型采样、服务端变化和并发调度会使提案、采用轨迹及数值结果不同。因此复现目标是核对来源、执行同一协议并保留独立原始证据，不能承诺逐 token、逐候选或最终分数完全一致。比较时按 stream 报告差异，保留失败和不可用测量；不挑选最像原结果的一次运行。

本入口的合成单元测试只验证来源篡改检测、路径保护、完整性检查和子进程隔离，不是正式模型实验，也不是收益证据。
