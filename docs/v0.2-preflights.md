# v0.2 engineering preflights and negative evidence

These development runs diagnose host integration. Their outcomes are not pooled with the formal seeds 101–110 experiment and are not presented as independent RSI improvements. Each directory retains original model output and execution evidence; large raw trees are distributed in the release evidence archive at the same repository-relative paths.

| Directory under `experiments/` | What actually happened | Consequence |
|---|---|---|
| `continual-pilot-baseline-v1` | Answering and memory extraction shared a conflicting output contract. No durable facts were written; recall failed. | Retained as aborted engineering preflight. A valid mechanism cannot compensate for a broken writer interface. |
| `continual-pilot-v2` | A separate writer still saw the original task/answer prompt and returned answer-shaped JSON instead of memory proposals; all three lanes stopped on writer schema validation. | Separated the fixed extraction conversation from the answer query and M prompt. |
| `continual-writer-smoke-v3` | Six real model calls completed a four-task write→recall→correction→recall episode, 4/4 correct. | Establishes functioning integration for one episode, without proving RSI benefit. |
| `continual-pilot-v4` | Two-round fixed-M and fixed-P lanes finished. Joint lane stopped on malformed model-generated AST JSON after physical request attempts. Original invalid output remains retained. | Added explicit model syntax/shape repair, per-physical-request identities and bounded measurement retries. This host change is conventional engineering, not evolved P/M. |
| `continual-preflight-v5` | All three four-round lanes and all frozen-version/audit readouts finished. Ordinary first-two-round loops passed; source-governance changes produced real failures. Each arm had two fully successful four-step loops out of four. | End-to-end pipeline smoke only. Namespace transfer ended 0/4 for both evolving arms. Formal sources were then frozen; this pilot is not pooled into the ten-stream acceptance. |

The formal `continual-v02-main` first interrupted after 421 complete transitions when the model provider rejected requests for insufficient balance. Verified checkpoint recovery added 80 committed transitions (501/600 total), then the provider again returned HTTP 402. Both histories remain retained. Partial round calls remain evidence of work attempted, not committed version transitions. Resume must preserve the completed states, archive unsealed round artifacts, and explicitly record any repeated unsealed work. Original failed calls and original abort reports must remain inspectable.

Later recovery reached **594/600 committed transitions** before two lanes stopped on model-output JSON parsing, rather than another HTTP 402: stream 101 / fixed-P at r18, new-policy fork, and stream 101 / joint at r16, old-policy fork (zero-based rounds). Both failures occurred while proposing contrastive M candidates inside policy meta-probes. Nested object/array closures were malformed; each lane exhausted two measurement request blocks of three physical attempts. Syntax-repair requests were actually sent with the exact prior invalid content and syntax-only feedback, but all three responses within each block were identical and remained invalid. All 12 responses ended with `stop`, with 972–1,577 completion tokens against a 5,000-token limit; none records a `length` finish or HTTP error. The [parse-interruption inspection](verification/v02-parse-interruption.json) binds all four original receipts by raw-byte SHA256 and retains per-attempt errors, content hashes, usage and request identities without copying full messages or credential values. These are unavailable measurements, not mechanism-performance zeros. A later recovery does not erase this historical interruption: uncommitted rounds and all attempted-call costs remain retained under the existing recovery rules.

A model proposal, verified JSON Pointer, accepted version or complete memory chain proves a particular execution event. Improvement requires the separate independent endpoints. Invalid or unavailable executions are never assigned a favorable score or a fabricated zero.

## Completed formal run and publication

The final recovery completed all 600 committed transitions and sealed 630 states. All 630 version reports, 50 P audits, 30 memory-disabled and 30 wide-context controls, and ten shared inputs completed without a readout interruption; full offline replay and archive validation passed. The negative primary comparisons and unknown invalid-search effects remain in the [formal results](../experiments/continual-v02-main/RESULTS.md). Stable [v0.2.0](https://github.com/Oxygen56/MoltWeave/releases/tag/v0.2.0) and its [publication receipt](verification/v02-stable-publication.json) supplement the historical interruption records above; they do not rewrite them.
